# Self-hosted Geist fonts

Variable WOFF2 files from the official [Vercel Geist repository](https://github.com/vercel/geist-font), retrieved August 31, 2026:

- `Geist.woff2`: `packages/next/dist/fonts/geist-sans/Geist-Variable.woff2`
- `GeistMono.woff2`: `packages/next/dist/fonts/geist-mono/GeistMono-Variable.woff2`

Both support weights 100–900 and are served locally by Vite in web and Electron builds. No external font service is contacted. See `LICENSE.txt` for the SIL Open Font License.
