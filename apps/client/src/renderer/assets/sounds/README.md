# Sons da interface

Os eventos usam o nome do arquivo, sem a extensão. Arquivos MP3 adicionados a esta pasta são encontrados automaticamente no build.

Nomes reservados:

- `join.mp3`
- `leave.mp3`
- `microphone-on.mp3`
- `microphone-off.mp3`
- `chat-notification.mp3`
- `screen-open.mp3`
- `screen-close.mp3`

Os sons de entrada, saída, chat e compartilhamento de tela têm arquivos próprios. O som de chat é preparado no gesto de entrada na sala para continuar disponível quando a aba ou janela estiver em segundo plano.
