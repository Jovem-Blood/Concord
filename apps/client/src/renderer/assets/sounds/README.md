# Sons da interface

Os eventos usam o nome do arquivo, sem a extensão. Arquivos MP3 adicionados a esta pasta são encontrados automaticamente no build.

Nomes reservados:

- `join.mp3`
- `leave.mp3`
- `microphone-on.mp3`
- `microphone-off.mp3`
- `chat-notification.mp3`
- `screen-open.mp3`
- `screen-close.mp3`

No momento, somente os sons de entrada e saída têm arquivos. Os demais eventos já estão conectados e passam a tocar assim que o MP3 correspondente for adicionado.
